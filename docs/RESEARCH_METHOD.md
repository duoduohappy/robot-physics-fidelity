# 第三档：受限诊断搜索实验

问题：转换后有多项参数差异时，能否在固定门槛下，用更少完整轨迹测试找到足以恢复通过的参数集合？研究对象是原生参数临时干预，不是未知物理参数估计或硬件标定。

候选从按身份对齐的原生模型数组自动取得，以 `rtol=1e-6, atol=1e-8` 区分变化，每行是一个干预单元。白名单为阻尼/摩擦损失、限位求解参数、关节执行器力区间、执行器增益/偏置、几何摩擦；最多 128 行。仅深拷贝目标模型恢复指定源值，数据从同一源初态重建。每次搜索检查源/目标指纹未变化。没有向 USD 或 XML 写入干预结果。

共同流程：先测试未恢复集合与全部候选恢复集合。若原始通过，返回 NO_FAILURE；若全候选恢复仍失败，返回 UNRESOLVED，说明白名单不足或原因不属于这些差异，不继续虚构归因。

四个方法使用相同门槛、候选和预算：

- singletons：逐行恢复，只能发现单项足以恢复通过的集合。
- ddmin：既有 Delta Debugging 的子集/补集消减，以 PASS 为保留谓词。
- unranked：按固定候选顺序累计恢复，再逐项删除；作为去掉残差排序的消融。
- ranked：源轨迹 0、0.05、0.1 秒的相同状态下，测量每行恢复带来的相对加速度平方残差下降，以此排序，累计恢复后消减。计时包含排序、候选测试和最小性验证，分别统计 forward 与完整 rollout 调用。

所有集合方法最后做完整删除轮次，直到没有单项可移除，才标记 1-minimal；不保证基数最少、唯一根因，也不保证非单调故障中的全局最优。达到完整轨迹预算返回 BUDGET_EXHAUSTED；不是已确认修复。

预定义 10 个合成故障场景：两关节接触装置的 3 初态 × 增益/阻尼/组合故障，以及留出方盒滑动阻尼故障。包含小幅阻尼及不活跃槽位/被 pair 覆盖的几何默认值作为干扰项。故障标签仅用于评分，不参与排序。默认 5 次重复，每个场景每轮以固定随机种子打乱方法顺序；重复不是 50 个独立场景。

另外保留真实 G1 屈膝转换失败。真实案例没有注入标签；不能计算“真实根因准确率”。工程 fixture 的留出初态/拓扑也不等于独立机构或机器人验证。

主要指标：完整注入集合找回率、错误入选项、完整 rollout 次数、相同状态 forward 次数、包含排序成本的总耗时。一次通过集合可能小于完整故障集合，必须同时披露；不能把“找到足够修复”当作“找到了所有缺陷”。最终数据见 `evidence/research/benchmark.json`。

这是基于既有最小化方法的领域适配研究。查重和来源见 RELATED_WORK.md；尚无独立论文评审或全球原创性证明。
