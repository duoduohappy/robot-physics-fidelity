# 第二档与第三档开发边界

第二档：可复用资产验收组件。增加按身份对齐的关节、惯量、执行器、碰撞和求解配置审计；完整公开数组指纹；任务清单批量执行；与批准基线做版本回归；机器可读 JSON、JUnit、CI 接入示例。保留 v1 的固定 CPU 路径和拒绝范围，新增小型程序化动力学场景与固定公开资产任务。版本回归指同一套组件比较两次运行的环境、输入、语义和轨迹摘要，不冒充实际测试过多个未安装的依赖版本。

第三档：有基线和消融的诊断研究模块。比较逐项对照、Delta Debugging 和同状态动力学残差排序后消减的受限干预搜索。提供已知故障、干扰参数、组合故障、留出场景及真实 G1 未解决案例。统计物理调用次数、总耗时、成功修复集合、误归因及预算不足；不得只统计有利案例。

研究只临时修改独立原生模型做干预，不向资产写入未知参数，不改变现有自动修复白名单；最小修复集合不等于唯一真实根因。若改进没有证据，明确报告负结果。Delta Debugging 和加权/排序搜索已有前人工作，本项目不宣称发明这些算法或全球唯一。

真实用户试用、团队实际节时、真实机器人及 sim-to-real 效果均需要外部证据，本机实现完成不等于这些效果已验证。
