# 2.1 固定 Go2 自动碰撞通道验收

本机实现与验收完成。独立版本 2.1.0 wheel 安装在单独 Python 3.11 venv，禁用系统 site-packages、无 PYTHONPATH；复用已经锁定校验的原始模型/依赖缓存。未再把自动回放算作真人试用。

- 33 项测试通过，含原有 21 项；规则测试对照原生 MuJoCo 接触，覆盖掩码、父子过滤、焊接体和 exclude。
- 新通道的 24 个有效碰撞几何建立唯一身份；276 个无序几何对的资格全部一致，其中 233 对有配置上的碰撞资格。不是说这些对在轨迹中全部发生过接触。
- home、raised、joint-offset、control-offset 四组各 0.5 秒，均满足原有位置/速度门槛，逐步接触对一致且无仿真警告。
- 五种受控 USD 故障全部阻断：矛盾掩码、禁用球体、错误半径、身份歧义返回 UNSUPPORTED；质量改变触发物理 FAIL。均未获得认证。这些是人工注入，不是声称转换器真实产生了五种缺陷。
- 正常官方导出被认证，明确 repair_required=false；撤销后同一文件变为未认证。没有生成伪修复候选、没有改变原始 XML/网格。
- 源文件变化、资产和回执篡改、不完整的通过报告以及未知源输入均被拦截；原始 Go2 21 文件的前后 SHA256 相同。
- 命令行、只读验证及新操作向导的自动回放通过；原有 7 案例回归符合预期，原显式 pair 入口对 Go2 仍拒绝。两个通道的资格没有混用。

范围仍严格限定为锁定的原版 Go2、球体/平面、固定依赖、报告记录的原生 CPU 运行配置和四组固定条件。没有其他机器人自动碰撞、长期策略、Newton 外层状态同步、真实硬件或业务采用证明。

历史 v2 研究实验未因这个更新重新运行；其报告继续标注原版本及合成数据限制，不把它们改写为本版新的研究成果。云端 CI 结果另有独立公开回执。
