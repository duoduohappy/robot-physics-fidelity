# Go2 自动碰撞支持：开发边界评估

**建议继续做一个独立、受限的自动碰撞验收通道，复用上游导入；当前不需要自研碰撞算法，也没有证据需要对这个 Go2 样例做参数修复。**生产 v2 契约仍未改变。

## 本次实际证据

原版 Go2、固定依赖、官方转换 USD、Newton 标准 add_usd 与 SolverMuJoCo CPU 路径。没有调用本项目 contactBridge 修复，没有清零原始掩码，没有改写源 XML，也未启用生产候选。显式对齐源初态、控制和既有求解配置，测试时长及位置/速度门槛沿用 v2。

24 个有效碰撞几何（球体和平面）按已建立的身体/关节身份、类型、有效尺寸与 home 同状态世界位置得到唯一的一一映射。这是探测身份，不是任意匿名 USD 的通用身份协议。原生源包含 57 个几何；目标原生模型只包含 24 个有效碰撞几何，视觉网格不纳入碰撞数量对等判断。

| 指标 | 结果 |
|---|---:|
| 身体位置分量最大差 | 5.8570777394795215e-9 m |
| qvel 分量最大差 | 2.7049412931745564e-8 |
| 观察到的接触对集合 | 源/目标相同，均为四个脚底与地面 |
| 既有 0.5 秒运动门槛 | 数值符合 |
| 原始文件 | 前后哈希相同 |
| 完整自动碰撞规则等价性 | 未证明 |
| 生产资产资格 | 未认证、未启用 |

主证据为 stock-import-measured.json。首次探测把球体不使用的 size 后两个分量也当成匹配条件，未建立映射而停止。按照 MuJoCo 球体仅使用半径的语义修正后得到以上结果；保留最初停止证据 stock-import.json，不将其当成转换器丢失几何的证明。

官方 converter 0.9.0 在本次 24 个碰撞 prim 上没有显式写入 mjc:contype/conaffinity；Newton 1.8.0 编译后的掩码值也不必逐项等于源值。这次轨迹和观察接触相同，不能据此推断任意非平凡掩码、父子过滤、exclude 或未触发接触都等价。

## 推荐最小开发范围

1. **先做验收，不制造修复。**读取官方导出 USD，复用标准导入。原始导出已满足目标时输出“无需修复”；不为了演示修复而改参数。
2. **独立通道及明确适用条件。**首批只覆盖固定 Go2 的单自由根/hinge、球体-平面自动碰撞、无显式 pair/无 exclude 的情况。非平凡掩码、混合 pair、mesh 碰撞、多个资产域及未知结构先拒绝，不直接放宽 v2。
3. **几何身份协议。**源编译指纹＋源几何索引＋USD 路径＋有效物理形状签名；一一对应验证。缺失/歧义时拒绝，不能盲目按数组顺序或最近位置猜测。验证至少两个初态，记录世界/局部坐标约定。
4. **有效碰撞资格检查。**在原/目标模型上覆盖 mask、同体/焊接体、父子过滤和排除规则，验证所有有资格/无资格的几何对。原始比特值相等不是唯一判据，观察到四个脚接触也不构成穷尽证明。
5. **行为验收与负例。**home 之外加入控制/初态变化；注入掩码错误、丢球体、错误半径及身份歧义，要求能检测并阻断。原位置/速度门槛不变；必须有实际接触证据。
6. **接入事务。**只有规则检查和行为检查均通过才交出已认证路径。继续保留原始资产、验证回执、失败不启用和资产选择回退；无需修复和修复成功要分别呈现。

## 现在不能宣称的结果

- Go2 已经通过生产 RPF 验收；
- 全部自动碰撞语义已无损往返；
- 原模型或任意 Newton 导入都可靠；
- 本次实现了原创自动碰撞算法；
- 长期运动、策略训练、真实机器人或 sim-to-real 已验证。

本次任务止于向导说明改进和边界评估；未实现上述新生产通道。下一次开发应按这六项验收，不扩大为新的仿真引擎。
